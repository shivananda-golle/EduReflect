# EduReflect — AI Study Assistant

Overview page for EduReflect, a retrieval-augmented study assistant: cited answers from a
knowledge base of 2,316 passages, quizzes generated from any answer, and Q&A over your own PDFs.

- Live app: <https://edureflect.streamlit.app/>
- Source, retrieval benchmark and setup notes: <https://github.com/shivananda-golle/EduReflect>

The app itself runs on Streamlit Community Cloud (free tier); this Space hosts the overview and
embeds the demo.
