How an answer is produced

  1. Two searches run in parallel. Semantic search (bge-small embeddings + FAISS) finds passages that mean the same thing; BM25 keyword search catches exact terms like "Heron's formula" or "nichrome".
  2. The rankings are fused. Reciprocal rank fusion merges both lists and keeps the best 5 passages.
  3. The model answers from those passages only. One call, with the passages numbered, so it can cite [1], [2] and say when the evidence doesn't cover the question.
  4. You see the evidence. The cited passages, a confidence rating, key terms and follow-up questions come back with the answer.

Built with

FastAPI · Streamlit · SQLAlchemy with Postgres · FAISS + fastembed (BAAI/bge-small-en-v1.5, ONNX, no PyTorch, ~380 MB total) · Groq (gpt-oss-20b with automatic fallback) · pytest and GitHub Actions. Daily budgets, per-user limits and sign-up throttling keep the public demo inside free quotas.
